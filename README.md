## Что это такое

Snake VPN — это ваш персональный VPN-сервер, который вы разворачиваете **одной командой** на своём VPS. Никаких сложных настроек, никакого программирования — просто запустите скрипт и следуйте подсказкам.

Snake VPN поддерживает несколько способов маскировки соединения и автоматически пробует доступные транспорты. Это может помочь в некоторых сетях, но не гарантирует обход любых блокировок или нераспознаваемость DPI. При блокировке самого IP может понадобиться другой входной сервер.

**Что умеет:**
- Несколько транспортов с маскировкой протокола
- Автоматическая ротация протоколов при блокировке
- Шифрование TLS + дополнительный паддинг пакетов
- Безлимитные ключи доступа — раздавайте друзьям и семье
- Контроль трафика, лимиты, статистика по каждому ключу
- Автоподключение при перезагрузке устройства
- Клиенты для Android и Windows

## Из чего состоит

| Компонент | Что делает | Платформы |
|-----------|------------|-----------|
| **Сервер** | Стоит на вашем VPS. Принимает VPN-подключения, управляет ключами | Linux (Docker) |
| **Менеджер** | Приложение для администратора. Создаёт ключи, показывает статистику, управляет сервером | Android, Windows |
| **Клиент** | Приложение для пользователя. Получает ключ и подключается к VPN | Android, Windows |

**Как это работает:**

1. Вы разворачиваете сервер на VPS (одна команда)
2. Устанавливаете Менеджер на телефон или ПК, вводите адрес сервера и токен
3. В Менеджере создаёте ключи доступа для себя и друзей
4. Каждый ключ — это ссылка `svpn://...`, которую вы отправляете пользователю
5. Пользователь открывает Клиент, вставляет ключ и подключается

**Как создать сервер:**

6. **Отключите** "Автоматическая резервная копия" — платить за это не нужно
7. Нажмите **"Создать"**

Сервер обойдётся менее **$3 в месяц**. После создания вам на почту придут данные для подключения: **IP-адрес**, **логин** (root) и **пароль**.

## Шаг 2. Купить домен

Домен нужен для автоматического выпуска доверенного TLS-сертификата через Let’s Encrypt. **Покупать сертификат отдельно не нужно** — он автоматически выпускается и продляется через Let's Encrypt.

Рекомендую [Timeweb Cloud](https://timeweb.cloud/r/cz11262) (буду благодарен за регистрацию по партнёрской ссылке).

**Как купить домен:**

1. Зарегистрируйтесь на [Timeweb Cloud](https://timeweb.cloud/r/cz11262)
2. Перейдите в раздел **"Домены"**
3. Введите желаемое название домена (например `myvpn.su`, `coolserver.su`)
4. Рекомендую зону **.su** — они дешёвые
5. Оплатите домен

**Как привязать домен к серверу:**

После покупки домена нужно создать **DNS-запись типа A**, которая свяжет ваш домен с IP-адресом VPS-сервера.

1. В панели Timeweb Cloud перейдите в настройки домена
2. Создайте **A-запись**: укажите IP-адрес вашего VPS (который пришёл на почту после покупки сервера)
3. Подождите 5-15 минут, пока DNS обновится

Подробная инструкция по настройке DNS: [Управление DNS-записями](https://timeweb.cloud/docs/domains/dns-records-management)

## Шаг 3. Установить Snake VPN на сервер

Подключитесь к серверу по SSH. На Windows откройте **Командную строку** (cmd) или **PowerShell** и введите:

```bash
ssh root@ВАШ_IP_АДРЕС
```

Например, если IP сервера `185.123.45.67`:

```bash
ssh root@185.123.45.67
```

Система спросит пароль — введите пароль, который пришёл на почту (при вводе символы не отображаются — это нормально, просто печатайте и нажмите Enter).

**Откройте TCP 22, 80 и 3389 в firewall хостера. Для настроенного whitelist/TURN дополнительно нужен UDP 56000. Затем скачайте и запустите установщик:**

```bash
curl -fsSL https://raw.githubusercontent.com/4eSyH/snake-vpn/main/install.sh -o install.sh
sudo bash install.sh
```

Скрипт сделает всё автоматически:
- Обновит систему и настроит файрвол
- Установит Docker
- Развернёт Snake VPN сервер
- Выпустит SSL-сертификат через Let's Encrypt
- Сгенерирует админ-токен

**Следуйте подсказкам скрипта** — он попросит ввести:
- **Доменное имя** — домен, который вы купили на шаге 2
- **Email** — для SSL-сертификата (можно любой)

По завершении скрипт покажет **админ-токен** — **обязательно сохраните его!** Он понадобится для подключения Менеджера.

## Шаг 4. Подключить Менеджер

Менеджер — это приложение администратора, через которое вы управляете сервером и ключами.

1. Скачайте Менеджер со страницы [Releases](https://github.com/4eSyH/snake-vpn/releases):
   - **Android** — файл `snake-vpn-manager.apk`
   - **Windows** — файл `SnakeVPN-Manager-Setup.exe`
2. Установите и откройте приложение
3. Нажмите **"Добавить сервер"** и введите:
   - **Имя** — любое удобное название (например "Мой VPN")
   - **URL сервера** — `https://ваш-домен.su:3389` (домен из шага 2)
   - **Админ-токен** — токен, который показал скрипт установки
4. Нажмите **"Сохранить"**

Если всё правильно — откроется панель управления с информацией о сервере: количество ключей, подключённые пользователи, трафик, аптайм.

## Шаг 5. Создать ключи и раздать пользователям

В Менеджере:

1. Перейдите в раздел **"Access Keys"**
2. Нажмите **"+ New Key"**
3. Введите имя ключа (например "Телефон Андрей", "Ноутбук мама", "Планшет жена")
4. Нажмите **"Создать"**
5. Нажмите на ключ → **"Скопировать ключ"** — скопируется ссылка вида `svpn://...`
6. Отправьте эту ссылку пользователю (через мессенджер, email и т.д.)

Создавайте **отдельный ключ на каждое устройство** — так удобнее отслеживать трафик и при необходимости отключить конкретное устройство.

---

## Шаг 6. Подключить клиент

Клиент — это приложение для конечного пользователя VPN.

1. Скачайте Клиент со страницы [Releases](https://github.com/4eSyH/snake-vpn/releases):
   - **Android** — файл `snake-vpn-client.apk`
   - **Windows** — файл `SnakeVPN-Setup.exe`
2. Установите и откройте приложение
3. Нажмите **+** (`Add server`), вставьте полный `svpn://` ключ в **Access Key** или нажмите **Paste from clipboard**, затем сохраните кнопкой **Add Server**
4. Нажмите **кнопку подключения**

Готово! VPN работает.

## Возможности Менеджера

Менеджер позволяет полностью управлять вашим VPN-сервером:

- **Статистика сервера** — общий трафик (входящий/исходящий), количество активных подключений, аптайм
- **Месячный трафик** — отслеживание потребления за текущий и предыдущие месяцы
- **Управление ключами** — создание, удаление, переименование ключей
- **Статистика по ключам** — трафик и количество подключений для каждого ключа отдельно
- **Лимиты трафика** — можно задать ограничение в ГБ на ключ (месячное или без ограничения)
- **Ограничение скорости** — лимит скорости в Мбит/с на каждый ключ
- **Срок действия** — можно задать дату, после которой ключ перестанет работать
- **Несколько серверов** — можно добавить несколько VPN-серверов и управлять ими из одного приложения

## Возможности Клиента

- **Автоподключение** — при запуске приложения автоматически подключается к последнему серверу
- **Несколько серверов** — можно добавить несколько ключей от разных серверов и переключаться между ними
- **Белый список URL** — список сайтов, трафик к которым идёт **напрямую**, минуя VPN (полезно для банков, госуслуг, локальных сервисов)
- **Работа в фоне** — VPN продолжает работать при сворачивании приложения
- **Автозапуск** (Android) — при перезагрузке телефона VPN запускается автоматически
- **Управление из шторки** (Android) — кнопки подключения/отключения прямо в уведомлениях
- **Автовыбор протокола** — клиент пробует доступные способы подключения

## Обновление

**Сервер** в стандартном Docker-развёртывании обновляется так:

```bash
cd /opt/snake-vpn && docker compose pull && docker compose up -d
```

Docker-образ обновляется отдельно от файлов GitHub Releases. `docker compose pull` скачивает образ, указанный в вашем Compose; номер последнего релиза не подтверждает версию образа. Для локально собранного или закреплённого образа используйте порядок обновления именно вашей установки. Сохраняйте конфиг, хранилище ключей и кеш сертификатов.

**Клиент и Менеджер** — скачайте новую версию со страницы [Releases](https://github.com/4eSyH/snake-vpn/releases) и установите поверх.

## FAQ

**Нужно ли покупать SSL-сертификат?**
Нет. Сертификат выпускается автоматически через Let's Encrypt и автоматически продляется. Бесплатно.

**Сколько пользователей можно подключить?**
Количество зависит от ресурсов сервера и нагрузки. Каждому устройству создайте отдельный ключ в Менеджере.

**VPN замедляет интернет?**
Скорость зависит от маршрута, провайдера, нагрузки сервера и выбранного транспорта; VPN добавляет накладные расходы.

**Что если провайдер заблокирует VPN?**
Клиент пробует разрешённые транспорты, но блокировка IP может потребовать другого входного сервера. Успех обхода заранее не гарантируется.

**Можно ли добавить несколько серверов?**
Да. И в Менеджере, и в Клиенте можно добавить несколько серверов.

**Данные ключей сохраняются при переустановке клиента?**
Перед переустановкой экспортируйте список серверов из клиента и сохраните ключи отдельно. Экспорт содержит секреты доступа: храните его безопасно.
